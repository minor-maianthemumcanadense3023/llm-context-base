## 🚀 Setting up your wiki

The application requires a folder on your machine to hold your data. Use a folder stored locally on your hard drive. 

1. Launch the application from your desktop or start menu.
2. Select "New Workspace" when the welcome screen appears.
3. Choose the folder you created in the previous step.
4. The application reads your folder. It checks for existing notes in Markdown format.
5. If you have no notes yet, create a new file with a .md extension inside your folder.
6. The software assigns metadata to your files. This allows the AI to understand the relationship between different notes.

## 🛠️ Using the tools

The application includes a system to check your notes for consistency. We call this the lint system.

1. Open your notes folder with any text editor or the integrated view mode.
2. If your notes do not meet the standard, a notification appears on the screen.
3. Follow the suggestion to fix the structure.
4. The training period runs automatically. It analyzes your text to learn your unique writing style and subject matter.
5. Use the search bar to ask questions. The system scans your entire folder. It provides a response rooted in your notes.

## 💡 System requirements

The application works on Windows 10 and Windows 11. It needs at least 8 GB of memory to run the language models effectively. A modern processor helps the software index larger amounts of text quickly. Keep your files in a local directory for the best speed. Cloud-synced folders such as OneDrive may cause delays during the index process.

## 📁 Managing your files

This tool turns your plain text files into a smart database. Use Markdown syntax to organize your thoughts. Use brackets to link two notes together. The application detects these links. It builds a map of your knowledge. 

- Use headers to create sections.
- Use bold or italic text to emphasize points.
- The metadata standard ensures the AI reads dates, tags, and categories correctly.
- If you change a file, the system updates the index in the background.

## 🛡️ Privacy and safety

Your data stays on your computer. The application does not send your notes to external servers. We prioritize local processing to keep your private thoughts secure. You control what the software sees by choosing which folder to index. You can remove the folder from the application at any time.

## 🧩 Troubleshooting common issues

If the application does not find your files, check the folder path. Ensure your notes have the .md file extension. If the interface feels sluggish, close other open programs to free up memory. Updates happen automatically when you restart the application. If you encounter errors, restart your computer and try again.

## 📋 Additional tips

- Start with simple notes.
- Use tags for broad categories.
- Update your notes often to keep the index fresh.
- Do not worry about formatting errors in the beginning. The lint system will guide you.
- Explore the settings menu to adjust how the AI displays answers.
- You can change the language model settings to prioritize speed over depth.
